# Wordle
Wordle is an internet, word, puzzle game that was released in 2021 and was so sensational that it was purchased by the New York Times for their game catalog. Each day has a mystery 5 letter word that the player tries to guess in a similar fashion to the Mastermind board game. 

There are three aspects to this directory:
- Data Analysis for Auptimal Word Play
- Bot that solves the Wordle 
- Playable Wordle Game
